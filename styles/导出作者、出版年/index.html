提示

请优先参阅 「安装样式文件」 以了解样式文件安装步骤和常见问题。

请确保 Zotero 正在运行，点击下面任意安装链接以安装样式。

本站为每一个样式文件都提供了多个下载地址，请选择自己可用的地址。

直接安装

单击以下任一链接，通过 Zotero Connector 直接安装：

  • 从 GitHub 安装样式
  • 从 Gitee 安装样式

备用链接

单击以下任一链接，若未执行自动安装请下载后手动安装：

  • 通过 Zotero 中文社区下载 （由本站直接提供，与 GitHub 同步更新）
  • 从 JsDeliver 下载样式 （此地址存在 24 h 延迟）
  • 从 oss.wieke.cn 下载样式 （此地址由网友可口可乐提供）
  • 从 oss.wwang.de 下载样式 （此地址由网友可口可乐提供）
  • 从 GH Proxy 下载样式 （需「右击->另存为」下载文件）
